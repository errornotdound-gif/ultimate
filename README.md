# 🚀 Railway Mailer Ultimate

## 📌 Description
Tool d'envoi d'emails massif exploitant le SMTP local de Railway.

## 🎯 Fonctionnalités
- Interface web fluide
- Grabber de senders automatique
- Envoi HTML/TXT
- Logs en temps réel
- Variables dynamiques

## 🚀 Déploiement
1. Fork ce repo
2. Connecter à Railway
3. Déployer automatiquement
